# 右侧属性面板 - 文档元数据接口文档 (v2.4)

## 概述
本文档专注于定义 MarkFlow 系统中**右侧属性面板（RightSidebar）**相关的 RESTful API。主要涵盖文档 YAML 元数据（标题、状态、标签等）的拉取与更新，以及文档间的关联关系和 Git 版本历史记录。

## 基础信息
- **Base URL**: `https://api.markflow.com/v2.4/document-properties`
- **数据交互格式**: `application/json`
- **鉴权方式**: HTTP Header `Authorization: Bearer <Token>`

---

## 1. 获取文档基础属性 (Frontmatter)
用于拉取当前激活文档的 YAML Frontmatter 元数据，填充右侧面板的标题、状态和标签等表单项。

- **接口路径**: `/{documentId}`
- **请求方法**: `GET`

### 请求参数 (Path)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `documentId` | `string` | 是 | 需要获取属性的文档唯一标识 |

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 (200表示成功) |
| `data` | `object` | 是 | 文档属性对象 |
| `data.title` | `string` | 是 | 文档标题 (对应 TITLE) |
| `data.status` | `string` | 是 | 评审状态 (对应 STATUS，如: `In-Review`, `Draft`, `Final`) |
| `data.tags` | `array` | 是 | 知识标签数组 (对应 TAGS) |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "title": "ADR-004-存储选型.md",
    "status": "In-Review",
    "tags": ["分布式", "存储架构"]
  }
}
```

## 2. 更新文档基础属性
当用户点击底部“应用属性变更”按钮时，将右侧面板中修改的标题、状态、标签等数据同步保存至服务端（写入文档的 YAML 头部）。

- **接口路径**: `/{documentId}`
- **请求方法**: `PATCH`

### 请求字段说明 (Body)
> 注：支持增量更新，传递需要修改的字段即可。

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | `string` | 否 | 修改后的文档标题 |
| `status` | `string` | 否 | 修改后的文档状态 |
| `tags` | `array` | 否 | 修改后的完整标签数组 |

### 请求参数示例
```json
{
  "title": "ADR-004-分布式存储选型.md",
  "status": "Final",
  "tags": ["分布式", "存储架构", "S3"]
}
```


### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `message` | `string` | 是 | 操作结果提示 |

### 响应示例
```json
{
  "code": 200,
  "message": "属性已同源同步至前端 YAML"
}
```

## 3. 获取关联前置文档
拉取当前文档依赖（DEPENDS_ON）的其他文档列表，用于渲染带有 Link 图标的关联文档区块。

- **接口路径**: `/{documentId}/dependencies`
- **请求方法**: `GET`

### 请求参数 (Path)
无额外参数，使用 URL 中的 `documentId`。

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `array` | 是 | 关联文档列表 |
| `data[].id` | `string` | 是 | 关联文档的 ID |
| `data[].title` | `string` | 是 | 关联文档的标题名称 |

### 响应示例
```json
{
  "code": 200,
  "data": [
    { "id": "doc_001", "title": "ADR-001-架构总览.md" },
    { "id": "doc_102", "title": "RFC-102-元数据同步.md" }
  ]
}
```

## 4. 获取 GIT 版本归档日志
拉取当前文档的 Git 提交历史，用于在右侧面板底部展示按时间倒序排列的版本轴。

- **接口路径**: `/{documentId}/commits`
- **请求方法**: `GET`

### 请求参数 (Query)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `limit` | `integer` | 否 | 返回的提交记录数量，默认 5 |

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `array` | 是 | 提交记录列表 |
| `data[].hash` | `string` | 是 | 简短的 Commit Hash（如: `8f2b10a`） |
| `data[].timeAgo` | `string` | 是 | 相对时间描述（如: `2 小时前`） |
| `data[].message` | `string` | 是 | 提交说明信息 |
| `data[].author` | `object` | 是 | 提交作者信息 |
| `data[].author.name` | `string` | 是 | 作者全名（如: `Alex Chen (陈希)`） |
| `data[].author.initials`| `string` | 是 | 作者首字母缩写，用于渲染无头像时的占位符（如: `AC`） |
| `data[].author.color` | `string` | 否 | 头像占位符的背景色（如: `#3b82f6`） |

### 响应示例
```json
{
  "code": 200,
  "data": [
    {
      "hash": "8f2b10a",
      "timeAgo": "2 小时前",
      "message": "docs(storage): 增补双可用区 Raft 一致性协议与专网容灾基线参数",
      "author": {
        "name": "Alex Chen (陈希)",
        "initials": "AC",
        "color": "#3b82f6"
      }
    }
  ]
}
```
