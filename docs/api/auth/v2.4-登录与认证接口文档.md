# 登录与认证接口文档 (v2.4)

## 概述
本文档定义了 MarkFlow 系统中用户认证与登录相关的 RESTful API。为了保证凭据传输的安全，前端在发起登录请求前，需将账号密码整体进行加密传输。

## 基础信息
- **Base URL**: `https://api.markflow.com/v2.4/auth` (开发环境对应 Mock 域名)
- **数据交互格式**: `application/json`

---

## 1. 账号密码登录
验证用户的用户名（邮箱）与密码。为了保障凭据在网络传输过程中的安全，前端在发起请求前，**必须**将包含 `email` 和 `password` 的 JSON 对象字符串整体进行加密，以单一密文形式进行传输。

- **接口路径**: `/login`
- **请求方法**: `POST`

### 请求参数 (Body)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `payload` | `string` | 是 | 将 `{"email":"...","password":"..."}` 整体经过加密编码后的密文 |

### 请求示例
```json
{
  "payload": "U2FsdGVkX19+abc123xyz987..."
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 (200表示成功，401表示未授权/密码错误) |
| `message` | `string` | 否 | 状态描述语 |
| `data` | `object` | 是 | 响应数据主体 |
| `data.token` | `string` | 是 | 用于后续接口请求鉴权的 Bearer Token |
| `data.user` | `object` | 是 | 登录用户的基础画像信息 |
| `data.user.id` | `integer`| 是 | 用户唯一标识 ID |
| `data.user.name` | `string` | 是 | 用户昵称/花名 |
| `data.user.email`| `string` | 是 | 用户邮箱 |
| `data.user.role` | `string` | 是 | 用户的系统角色（如：Owner / Staff Arch） |
| `data.user.avatarUrl`| `string`| 是 | 用户头像 URL |

### 响应示例 (成功)
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM...",
    "user": {
      "id": 1,
      "name": "Alex Chen",
      "email": "alex.chen@markflow.io",
      "role": "Owner / Staff Arch",
      "avatarUrl": "https://api.dicebear.com/7.x/avataaars/svg?seed=Alex"
    }
  }
}
```

### 响应示例 (失败)
```json
{
  "code": 401,
  "message": "邮箱或访问凭据错误，请重试",
  "data": null
}
```
