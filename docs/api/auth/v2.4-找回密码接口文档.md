# 找回密码接口文档 (v2.4)

## 概述
本文档定义了 MarkFlow 系统中关于**找回密码（发送重置链接）**相关的 RESTful API。

## 基础信息
- **Base URL**: `https://api.markflow.com/v2.4/auth` (开发环境对应 Mock 域名)
- **数据交互格式**: `application/json`

---

## 1. 发送重置密码链接
用户在找回密码页面输入工作邮箱后，调用此接口触发系统下发一键重置密码的邮件链接。

- **接口路径**: `/password/forgot`
- **请求方法**: `POST`

### 请求参数 (Body)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `email` | `string` | 是 | 用户的注册工作邮箱 (Work Email) |

### 请求示例
```json
{
  "email": "alex.chen@markflow.io"
}
```

### 响应示例 (成功)
```json
{
  "code": 200,
  "message": "重置链接已发送",
  "data": null
}
```
