# 重置密码接口文档 (v2.4)

## 概述
本文档定义了 MarkFlow 系统中关于**重设新密码**相关的 RESTful API。

## 基础信息
- **Base URL**: `https://api.markflow.com/v2.4/auth` (开发环境对应 Mock 域名)
- **数据交互格式**: `application/json`

---

## 1. 提交重置密码
用户通过邮箱内的重置链接进入重设密码页面（URL 中通常会携带 `resetToken`），填写新密码后调用此接口完成密码重置。
*注：为了安全起见，新密码传输时同样需要使用 `/public-key` 接口获取的动态 RSA 公钥进行加密传输。*

- **接口路径**: `/password/reset`
- **请求方法**: `POST`

### 请求参数 (Body)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `resetToken` | `string` | 是 | 邮件重置链接中携带的临时授权凭证 |
| `newPassword`| `string` | 是 | 经过 RSA 公钥加密并 Base64 编码后的新密码 |
| `keyId`      | `string` | 是 | 获取公钥接口返回的 `keyId`，用于后端匹配私钥解密 |
| `logoutOther`| `boolean`| 否 | 是否强制登出其他所有已登录的设备（默认为 true） |

### 请求示例
```json
{
  "resetToken": "temp-token-from-email-link-123456",
  "newPassword": "U2FsdGVkX19+xyz987...",
  "keyId": "key-20231101-abc123",
  "logoutOther": true
}
```

### 响应示例 (成功)
```json
{
  "code": 200,
  "message": "密码重置成功",
  "data": null
}
```
