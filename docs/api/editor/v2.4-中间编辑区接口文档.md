# 中间编辑区 - 文档内容与 AI 辅助接口文档 (v2.4)

## 概述
本文档专注于定义 MarkFlow 系统中**中间编辑区（EditorArea）**相关的 RESTful API。主要涵盖文档正文源码的拉取与自动保存、文档的格式化导出，以及基于大模型的智能行内文本润色功能。

## 基础信息
- **Base URL**: `https://api.markflow.com/v2.4/editor`
- **数据交互格式**: `application/json`
- **鉴权方式**: HTTP Header `Authorization: Bearer <Token>`

---

## 1. 获取文档正文内容
拉取指定文档的 Markdown 纯源码。前端拿到源码后，在“分屏对齐”或“只读渲染”模式下通过本地的 Markdown 解析器渲染 HTML 视图。

- **接口路径**: `/{documentId}/content`
- **请求方法**: `GET`

### 请求参数 (Path)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `documentId` | `string` | 是 | 文档唯一标识 |

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 (200表示成功) |
| `data` | `object` | 是 | 响应数据对象 |
| `data.source` | `string` | 是 | Markdown 纯文本源码内容 |
| `data.lastSavedAt` | `string` | 是 | 最后一次成功备份/保存的 ISO 8601 时间戳 |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "source": "## 4. 存储集群健康探测代码实现\n```go\npackage main\n\nimport (\n  \"context\"\n)\n```",
    "lastSavedAt": "2025-02-28T14:32:00Z"
  }
}
```

## 2. 自动备份/保存文档正文
当用户在左侧“纯源码”面板输入内容时，前端进行防抖（Debounce）处理后，静默调用此接口将源码持久化。对应 UI 中的 “已自动备份” 徽章。

- **接口路径**: `/{documentId}/content`
- **请求方法**: `PUT`

### 请求字段说明 (Body)
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `source` | `string` | 是 | 全量的 Markdown 源码内容 |

### 请求参数示例
```json
{
  "source": "修改后的 Markdown 正文内容..."
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `message` | `string` | 是 | 操作提示 |

### 响应示例
```json
{
  "code": 200,
  "message": "文档已自动备份"
}
```

## 3. 请求 AI 智能润色建议
对应源码编辑器中选中文本后触发的 “AI 智能架构润色 (CLAUDE 3.5 SONNET)” 功能。提交选中片段给大模型，获取优化后的文本建议及置信度。

- **接口路径**: `/ai/polish`
- **请求方法**: `POST`

### 请求字段说明 (Body)
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `documentId` | `string` | 是 | 当前编辑的文档 ID（用于大模型提取上下文语义） |
| `originalText` | `string` | 是 | 用户选中的需要润色的原始文本 |
| `mode` | `string` | 否 | 润色模式（可选值: `enhance_semantic`(语义增强), `fix_grammar`(修正语法), `summarize`(总结)），默认 `enhance_semantic` |

### 请求参数示例
```json
{
  "documentId": "doc_101",
  "originalText": "生产环境存储网关集群必须在双可用区部署，同时要求元数据存储层采用 Raft 一致性协议以避免脑裂情况发生。",
  "mode": "enhance_semantic"
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `object` | 是 | AI 建议结果 |
| `data.suggestedText` | `string` | 是 | 大模型生成的优化后文本 |
| `data.confidence` | `number` | 是 | 置信度百分比（如 `99.4` 代表 99.4%） |
| `data.diff` | `object` | 否 | （可选）精确的增删字符差异，用于在编辑器中渲染 diff 视图 |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "suggestedText": "在生产环境中，对象存储网关节点必须实施跨双可用区 (Multi-AZ) 高可用冗余；元数据共识层需严格基于 Raft 分布式一致性协议构建，确保主备切换判定在 300ms 内收敛且彻底根除脑裂 (Split-Brain) 风险。",
    "confidence": 99.4
  }
}
```

## 4. 导出文档
对应顶部工具栏的“导出”按钮。将当前文档的渲染结果或源码打包为指定格式的文件供用户下载。

- **接口路径**: `/{documentId}/export`
- **请求方法**: `POST`

### 请求字段说明 (Body)
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `format` | `string` | 是 | 导出的文件格式（可选值: `pdf`, `html`, `markdown`） |
| `includeFrontmatter`| `boolean`| 否 | 是否在导出的文件中包含 YAML 元数据，默认 `false` |

### 请求参数示例
```json
{
  "format": "pdf",
  "includeFrontmatter": true
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `object` | 是 | 导出结果 |
| `data.downloadUrl` | `string` | 是 | 导出文件的临时下载直链（有效期通常为 5 分钟） |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "downloadUrl": "https://download.markflow.com/tmp/export-doc_101-12345.pdf"
  }
}
```
