# 关系图谱 - 节点与边数据接口文档 (v2.4)

## 概述
本文档专注于定义 MarkFlow 系统中**关系图谱（GraphArea）**相关的 RESTful API。主要用于获取用于 React Flow 渲染的节点（Nodes）和边（Edges）的数据集合。

## 基础信息
- **Base URL**: `https://api.markflow.com/v2.4/graph`
- **数据交互格式**: `application/json`
- **鉴权方式**: HTTP Header `Authorization: Bearer <Token>`

---

## 1. 获取图谱节点与关联数据
根据当前的上下文（如选中的根节点，或全局视口），拉取渲染图谱所需的所有节点及其连线关系。

- **接口路径**: `/data`
- **请求方法**: `GET`

### 请求参数 (Query)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `rootId` | `string` | 否 | 聚焦的中心节点 ID。如果不传，则返回全局视口的默认节点集 |
| `depth` | `integer` | 否 | 关联的层级深度，默认 `2` |

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 (200表示成功) |
| `data` | `object` | 是 | 图谱数据对象 |
| `data.nodes` | `array` | 是 | 节点数组 (符合 React Flow 结构) |
| `data.edges` | `array` | 是 | 连线数组 (符合 React Flow 结构) |
