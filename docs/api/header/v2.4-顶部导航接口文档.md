# 顶部导航 - 上下文与用户信息接口文档 (v2.4)

## 概述
本文档专注于定义 MarkFlow 系统中**顶部导航（TopHeader）**相关的 RESTful API。主要涵盖顶部面包屑上下文的获取、全局搜索前置状态，以及当前登录用户的基础信息获取。

## 基础信息
- **Base URL**: `https://api.markflow.com/v2.4/header`
- **数据交互格式**: `application/json`
- **鉴权方式**: HTTP Header `Authorization: Bearer <Token>`

---

## 1. 获取当前文档面包屑上下文
当用户打开某个文档或处于某个工作区时，拉取其顶部面包屑路径，用于展示层级归属（如 `Engineering Wiki / main`）。

- **接口路径**: `/context`
- **请求方法**: `GET`

### 请求参数 (Query)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `documentId` | `string` | 否 | 当前激活文档的 ID。如果不传，则返回用户默认工作区的根级面包屑 |

### 请求参数示例
```json
{
  "documentId": "doc_101"
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 (200表示成功) |
| `data` | `object` | 是 | 面包屑数据对象 |
| `data.workspaceName` | `string` | 是 | 当前所属工作区/知识库名称（如: `Engineering Wiki`） |
| `data.branchOrTag` | `string` | 否 | 当前所处分支或版本标签（如: `main`） |
| `data.paths` | `array` | 否 | 从根目录到当前文档的完整路径层级数组 |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "workspaceName": "Engineering Wiki",
    "branchOrTag": "main",
    "paths": [
      { "id": "architecture", "title": "架构设计" },
      { "id": "doc_101", "title": "ADR-004-存储选型" }
    ]
  }
}
```

## 2. 获取当前登录用户信息
用于渲染顶部导航右侧的用户头像（Avatar）及基础权限标识。

- **接口路径**: `/user-profile`
- **请求方法**: `GET`

### 请求参数
无

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `object` | 是 | 用户信息对象 |
| `data.userId` | `string` | 是 | 用户唯一标识 |
| `data.userName` | `string` | 是 | 用户显示昵称 |
| `data.avatarUrl` | `string` | 是 | 用户头像图片 URL |
| `data.role` | `string` | 是 | 当前工作区角色（如: `admin`, `editor`, `viewer`） |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "userId": "usr_felix_998",
    "userName": "Felix",
    "avatarUrl": "https://api.dicebear.com/7.x/avataaars/svg?seed=Felix",
    "role": "admin"
  }
}
```

## 3. 生成文档分享链接
对应顶部导航右侧的“分享”按钮，为当前工作区或当前激活的文档生成一个可供外部/团队访问的快捷链接。

- **接口路径**: `/share-link`
- **请求方法**: `POST`

### 请求字段说明 (Body)
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `targetId` | `string` | 是 | 需要分享的目标 ID（如文档 ID 或工作区 ID） |
| `expiresIn` | `integer` | 否 | 链接过期时间（秒），默认不过期 |

### 请求参数示例
```json
{
  "targetId": "doc_101",
  "expiresIn": 86400
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `object` | 是 | 结果对象 |
| `data.shareUrl` | `string` | 是 | 生成的短链接地址 |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "shareUrl": "https://markflow.com/s/xyz789"
  }
}
```

## 4. 快速新建文档
对应顶部导航右侧的“新建文档”按钮，支持指定存储目录、Frontmatter 元数据预设、模板类型以及是否启用 AI 智能生成大纲。

- **接口路径**: `/document`
- **请求方法**: `POST`

### 请求字段说明 (Body)
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | `string` | 是 | 初始标题（如: `ADR-005-分布式元数据同步方案.md`） |
| `parentId` | `string` | 否 | 父级文件夹 ID (如: `architecture`)，不传则默认根目录 |
| `frontmatter` | `string` | 否 | 元数据预设方案 (可选值: `standard`, `minimal`, `none`)，默认 `standard` |
| `templateId` | `string` | 否 | 文档模板 ID (可选值: `blank`, `adr`, `rfc`, `api`)，默认 `blank` |
| `enableAi` | `boolean`| 否 | 是否启用 AI 智能生成框架大纲 |
| `aiPrompt` | `string` | 否 | AI 生成的提示词，当 `enableAi` 为 true 时必填 |

### 请求参数示例
```json
{
  "title": "ADR-005-分布式元数据同步方案.md",
  "parentId": "architecture",
  "frontmatter": "standard",
  "templateId": "adr",
  "enableAi": true,
  "aiPrompt": "针对跨区域混合云部署的元数据 Raft 复制与分片路由方案设计"
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `object` | 是 | 新文档的元数据 |
| `data.documentId` | `string` | 是 | 新建文档的唯一标识，前端拿到后用于跳转至编辑态 |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "documentId": "doc_new_999"
  }
}
```

## 4.1 新建 REST API 接口文档
作为“快速新建文档”的特殊模板扩展（`templateId: api`）。当用户选择“API 接口设计定义”模板并启用 AI 时，可以通过此专用接口，直接输入自然语言描述，由大模型自动生成标准的 OpenAPI / REST 协议格式及 cURL 用例的 Markdown 文档。

- **接口路径**: `/document/api-template`
- **请求方法**: `POST`

### 请求字段说明 (Body)
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | `string` | 是 | 接口文档标题（如: `用户登录注册接口文档.md`） |
| `parentId` | `string` | 否 | 存储目录的父级文件夹 ID |
| `apiDescription` | `string` | 是 | 对接口业务逻辑、输入输出字段的自然语言描述 |
| `apiType` | `string` | 否 | 接口风格（可选值: `rest`, `graphql`, `rpc`），默认 `rest` |

### 请求参数示例
```json
{
  "title": "v2.4-用户鉴权模块接口.md",
  "parentId": "api_docs_folder",
  "apiDescription": "需要一个用户登录接口，POST /login，传入手机号和密码，返回 JWT Token 和用户信息；还要一个刷新 Token 的接口。",
  "apiType": "rest"
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `object` | 是 | 包含生成的完整 Markdown 源码及文档 ID |
| `data.documentId` | `string` | 是 | 新建的文档 ID |
| `data.source` | `string` | 是 | 由 AI 自动生成的包含表格、请求响应示例的 Markdown 源码 |

### 响应示例
```json
{
  "code": 200,
  "data": {
    "documentId": "doc_api_888",
    "source": "# 用户鉴权模块接口\n\n## 1. 用户登录\n**POST** `/login`\n..."
  }
}
```

## 5. 全局搜索
对应顶部导航中间的搜索框（快捷键 `⌘K`），支持根据关键字全文检索文档、知识标签或代码片段。

- **接口路径**: `/search`
- **请求方法**: `GET`

### 请求参数 (Query)
| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | `string` | 是 | 搜索关键字 |
| `type` | `string` | 否 | 检索范围类型（如: `all`, `document`, `tag`, `code`），默认 `all` |
| `limit` | `integer` | 否 | 返回结果的最大数量，默认 10 |

### 请求参数示例
```json
{
  "keyword": "存储",
  "type": "document",
  "limit": 5
}
```

### 响应字段说明
| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `integer` | 是 | 业务状态码 |
| `data` | `array` | 是 | 搜索结果列表 |
| `data[].id` | `string` | 是 | 命中的资源唯一标识 |
| `data[].title` | `string` | 是 | 资源的标题或名称 |
| `data[].type` | `string` | 是 | 资源类型 (`document` / `tag` / `code`) |
| `data[].highlight` | `string` | 否 | 包含高亮 HTML 标签（如 `<em>`）的匹配内容片段 |
| `data[].url` | `string` | 是 | 点击后跳转的相对路由或资源定位符 |

### 响应示例
```json
{
  "code": 200,
  "data": [
    {
      "id": "doc_101",
      "title": "ADR-004-存储选型",
      "type": "document",
      "highlight": "最终决定使用 S3 作为核心<em>存储</em>方案...",
      "url": "/workspace/docs/doc_101"
    },
    {
      "id": "tag_002",
      "title": "分布式存储",
      "type": "tag",
      "highlight": null,
      "url": "/workspace/tags/tag_002"
    }
  ]
}
```
