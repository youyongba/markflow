# My App Boilerplate

This is a full-stack monorepo boilerplate featuring:
- **apps/web**: Next.js frontend with Redux Toolkit and basic page skeleton.
- **apps/server**: Express.js backend designed to be integrated with Next.js or run standalone.
- **packages/shared-***: Shared constants, types, and utilities for the monorepo.

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Run in development mode:
   ```bash
   pnpm dev
   ```

3. Build for production:
   ```bash
   pnpm build
   ```
